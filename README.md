# Task Flow Guide

I want to add task handling functionality to the shenas app with functionality similar to taskwarrior. It should be smart about how to minimize information and guide ones next task without overwhelming oneself, but also allow interaction. Perhaps by grouping tasks? Overview in a Kanban-style setting?
